**Test ID:** UT-11-11
**Test Case Name:** Success Page Handles Missing Database Record
**Test Type:** Unit
**Test URL / Location:**

- File: `base_application/tests/test_upload.py

- **Class:** UploadViewTests
  **Method:** `test_success_page_handles_missing_db_record`
  **Context:** Local Execution

```bash
python manage.py test base_application.tests.test_upload.UploadViewTests.test_success_page_handles_missing_db_record
```

**Description:**
This test ensures that the success page can still render correctly even if a file exists in the upload directory without an associated `SubmittedFile` database record. It verifies that the page gracefully displays the filename and provides a valid download link.

**Preconditions:**

- Authenticated test user (password-change flag cleared), if required.
- Test overrides active (temporary `MEDIA_ROOT` assigned to `TEMP_MEDIA`).

**Test Data:**

- Filename: `manual.py`
- Content: `print('no db record')` `(MIME: text/x-python)`

**Execution Steps:**

1. Manually create a file in `TEMP_MEDIA/uploads/manual.py`
2. Send `GET` request to `/upload_success?f=manual.py`
3. Inspect response body for filename `manual.py`
4. Inspect response body for link `/media/uploads/manual.py`

**Expected Result:**

- The success page loads with HTTP 200.
- The filename `manual.py` is displayed in the response.
- A download link `/media/uploads/manual.py` is rendered even without a database record.

**Post-Conditions:**

- The manually created file remains in the uploads directory after test execution.
- No `SubmittedFile` record is created automatically in the database.
- Application remains stable without throwing exceptions.

**Associated Requirements:**
FR-3, FR-11
