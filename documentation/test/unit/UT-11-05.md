**Test ID:** UT-11-05
**Test Case Name:** Extension Rules - Advanced
**Test Type:** Unit
**Test URL / Location:**

- File: `base_application/tests/test_upload.py`
  **Class:** UploadViewTests
  **Method:** `test_extension_rules_advanced`
  **Context:** Local Execution

```bash
python manage.py test base_application.tests.test_upload.UploadViewTests.test_extension_rules_advanced -v 2
```

**Description:**
Validate that the upload endpoint accepts .py files regardless of case (e.g., .PY) and rejects files with double extensions (e.g., .py.txt) with the user-facing error message “Only .py files are allowed.”

**Preconditions:**

- Django test client available.
- Test overrides in place (temporary MEDIA_ROOT, `ALLOWED_HOSTS` includes `testserver`, `SECURE_SSL_REDIRECT=False`).
- Authenticated test user (password-change flag cleared), if required.
- Upload validator configured to allow only .py (case-insensitive).

**Test Data:**

- Allowed File:
  - Filename: `upper.PY`
  - Content: `print(1)` `(MIME: text/x-python)`
- Rejected File:
  - Filename: `tricky.py.txt`
  - Content: `print(1)` `(MIME: text/plain)`

**Execution Steps:**

1. Create an in-memory file `upper.PY` with contents `print(1)\n` and `content_type="text/x-python"`.
2. `POST` to `reverse("upload")` with `file=upper.PY` and `follow=False`; capture response `response_two`.
3. Create an in-memory file `tricky.py.txt` with contents `print(1)\n` and `content_type="text/plain"`.
4. `POST` to `reverse("upload")` with `file=tricky.py.txt` and `follow=True`; capture response `response_two`.
5. Inspect `response_two` content for the validation message.

**Expected Result:**

- Accept uppercase `.PY`: `response_one.status_code` == **302** (redirect indicates success).
- Reject double extension: `response_two.status_code` == **200** (form re-render) and page contains `Only .py files are allowed`.

**Post-Conditions:**

- For the accepted `.PY`, upload proceeds as normal (file may be persisted depending on surrounding test fixtures).
- For the rejected `.py.txt`, no file is persisted and no DB row is created.
