**Test ID:** UT-11-02
**Test Case Name:** Accept Valid .py Upload
**Test Type:** Unit
**Test URL / Location:**

- File: `base_application/tests/test_upload.py`
  **Class:** UploadViewTests
  **Method:** `test_accepts_valid_py`
  **Context:** Local Execution

```bash
python manage.py test base_application.tests.test_upload.UploadViewTests.test_accepts_valid_py -v 2
```

**Description:**
Validate that uploading a valid `.py` file results in a redirect to the success page with a query string `?f=<saved_name>`.

**Preconditions:**

- Django test client available.
- Test overrides in place (temporary MEDIA_ROOT, `ALLOWED_HOSTS` includes `testserver`, `SECURE_SSL_REDIRECT=False`).
- Authenticated test user (password-change flag cleared), if required.

**Test Data:**

- Filename: `script.py`
- Content: `b"print('hello')\n"` `(MIME: text/x-python)`

**Execution Steps:**

1. `POST /` with form data `file=SimpleUploadedFile("script.py", b"print('hello')\n")`.
2. Inspect `Location` header of the response.

**Expected Result:**

- Status code **302**.
- `Location` contains **`/success/?f=`**.

**Post-Conditions:**

- A file has been saved under `uploads/`.

**Associated Requirements:**
FR-11
