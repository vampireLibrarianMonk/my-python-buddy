**Test ID:** UT-15-02
**Test Case Name:** Chat Bot Code Prompt Validation (Code Response & Guardrails)
**Test Type:** Unit
**Test Context:** Local Execution
**Test URL / Location:**

- **File:** `base_application/tests/test_chat_bot.py`

- **Class:** `ChatCodeTests`
  **Methods:**
  - `test_chat_llm_code_response`
  - `test_chat_llm_secure_code_response`

```bash
python manage.py test base_application.tests.test_chat_bot.ChatCodeTests
```

**Description:**

This test suite will serve to validate behavior of the code prompt mechanism of the chat bot.

**Preconditions:**

- Django test client is made available.
- `SECURE_SSL_REDIRECT=False` override setting is made to prevent 301 errors.
- Chat endpoint routes (`chat_reset`, `chat_llm`) are configured properly.
- Local GGUF model accessible at `models/<GGUF_FILE_NAME>`.
- Proper NVIDIA Driver and CUDA Runtime is installed.

**Test Data:**

| Field             | Example Value                                                   | Notes                          |
| ----------------- | --------------------------------------------------------------- | ------------------------------ |
| Code Prompt       | Write a Python function to add two numbers."                    | Standard code query            |
| Secure Term Input | `f"{search_term} a {secure_term} way to do a particular task."` | Ensures guardrail is activated |

**Automated Execution Steps:**

#### Secure-Term & Code Response Filtering

1. Generate all secure term and code term combinations. (`test_chat_llm_code_response`)
2. Ensure each response returns the security guardrail statement. (`test_chat_llm_secure_code_response`)

**Expected Result:**

- Code request prompt is deterministic and returns expected Python code block.
- Guardrail against requesting possible attack vector code or security liable code is enforced.

**Post-Conditions:**

- Guardrails are enforced consistently per their regex definitions.
- All responses are structured well (JSON) and predictable.

**Associated Requirements:**
FR-11, FR-15
