**Test ID:** UT-11-12
**Test Case Name:** Success Redirects If Filename Missing
**Test Type:** Unit
**Test URL / Location:**

- File: `base_application/tests/test_upload.py`
  **Class:** UploadViewTests
  **Method:** `test_success_redirects_if_filename_missing`
  **Context:** Local Execution

```bash
pytest base_application/tests/test_upload.py -k "test_success_redirects_if_filename_missing"
```

**Description:**
This test ensures that the `upload_success` view correctly handles cases where the querystring parameter `?f=<filename>` is missing. It verifies that the user is redirected back to the upload page instead of rendering the success page.

**Preconditions:**

- Authenticated test user (password-change flag cleared), if required.
- Application routes for `upload` and `upload_success` are available.

**Test Data:**

- No filename supplied in querystring.

**Execution Steps:**

1. Send `GET` request to `/upload_success` with no `?f` parameter.
2. Inspect the response status code.
3. Inspect the response redirect URL.

**Expected Result:**

- The response returns HTTP 302 (redirect).
- The redirect target is the `/upload` page.

**Post-Conditions:**

- No file is created in the uploads directory.
- No database records are created.
- Application remains stable without exceptions.

**Associated Requirements:**
FR-11
