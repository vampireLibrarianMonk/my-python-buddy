**Test ID:** UT-11-06
**Test Case Name:** Success Page Link & Disk Presence
**Test Type:** Unit  
**Test URL / Location:**  
    - File: `base_application/tests/test_upload.py`  
    - GitHub Commit URL: 
**Class:** UploadViewTests  
**Method:** `test_file_is_saved_under_uploads`  
**Context:** Local Execution
```bash
python manage.py test base_application.tests.test_upload.UploadViewTests.test_file_is_saved_under_uploads -v 2
``` 

**Description:**  
After posting a valid `.py` file to the upload view, verify the response is a redirect (**302**) whose Location contains `?f=<saved_name>`. Then `GET` the redirect target and confirm a **200** OK, the page renders a working `/media/uploads/<saved_name>` link and echoes the filename. Finally, assert the file exists on disk under `TEMP_MEDIA/uploads/<saved_name>`.

**Preconditions:**  
- Django test client available.  
- Test overrides in place (temporary MEDIA_ROOT, `ALLOWED_HOSTS` includes `testserver`, `SECURE_SSL_REDIRECT=False`).  
- Authenticated test user (password-change flag cleared), if required.  
- Uploads subdirectory writeable: TEMP_MEDIA/uploads/.

**Execution Steps:**  
1. `POST` to `reverse("upload")` with form data `{"file": <SimpleUploadedFile>}` and `follow=False`.
2. Assert status code is **302** and grab `Location` header.
3. Parse `file_object` query param from `Location (urlparse(...).query` --> `parse_qs(...).get("f"))` and assert it is not `None` (failure msg: `Redirect missing ?f=<filename>`).
4. `GET` the `Location URL`.
5. Assert status code is **200**.
6. Assert response contains `/media/uploads/<f>` and also contains the plain filename `<f>`.
7. Build `path = os.path.join(TEMP_MEDIA, "uploads", file_object)` and assert `os.path.exists(path)`.

**Expected Result:**  
- Initial response is a redirect including `?f=<saved_name>`.
- Success page returns **200** and shows a `View/Download` link pointing to `/media/uploads/<saved_name>` and displays the filename.
- File exists on disk under `TEMP_MEDIA/uploads/<saved_name>`.

**Post-Conditions:**  
- File persisted on disk under the temporary media root.
- (Optional, view-dependent) DB row created for the upload.
