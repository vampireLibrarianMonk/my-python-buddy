**Test ID:** UT-11-09
**Test Case Name:** Unicode Filename Saved and Linked
**Test Type:** Unit
**Test URL / Location:**

- File: `base_application/tests/test_upload.py`
  **Class:** UploadViewTests
  **Method:** `test_unicode_filename_saved_and_linked`
  **Context:** Local Execution

```bash
python manage.py test base_application.tests.test_upload.UploadViewTests.test_unicode_filename_saved_and_linked
```

**Description:**
After uploading a file with a Unicode filename, verify the redirect query string contains `?f=<saved_name>`, the success page shows a working download link using the saved name, the database preserves the original Unicode filename→ and the file exists on disk under the temporary media root.

**Preconditions:**

- Authenticated test user (password-change flag cleared), if required.
- Test overrides active (temporary `MEDIA_ROOT` assigned to `TEMP_MEDIA`).
- `SubmittedFile` model available with `saved_name` and `original_name fields`.

**Test Data:**

- Filename: `naïve_测试.py`
- Content: `print(42)\n` `(MIME: text/x-python)`

**Execution Steps:**

1. Upload `naïve_测试.py` and capture Location from the **302** response.
2. Parse `?f=<saved_name>` from `Location`.
3. `GET` the success page via `Location`; inspect for `/media/uploads/<saved_name>` link.
4. Query `SubmittedFile` by saved*name and assert `original_name == "naïve*测试.py"`.
5. Assert file exists at `TEMP_MEDIA/uploads/<saved_name>`.

**Expected Result:**

- Redirect includes `?f=<saved_name>`.
- Success page shows `View/Download` link using `/media/uploads/<saved_name>`.
- Database row created with `original_name` exactly `naïve_测试.py`.
- File exists on disk under the temporary media root.

**Post-Conditions:**

- File persisted; database row created with original Unicode filename preserved.

**Associated Requirements:**
FR-3, FR-11
