**Description:**
This suite validates the execution logic of the asynchronous `run_analyzer_task` function.
It ensures that supported analyzers (`bandit`, `dodgy`, `mypy`, `semgrep`, `vulture`) correctly transition their associated `Run` records from **REQUESTED → COMPLETED**, create one or more `Finding` entries→ and reflect accurate findings counts.

It also verifies the system’s error-handling path by testing an unsupported analyzer, ensuring that such cases mark the run as **ERRORED** and produce no findings.

**Preconditions:**

- Authenticated test user with valid session (if required).
- Active test media configuration (`TEMP_MEDIA` or equivalent).
- Each analyzer has a corresponding vulnerable test file:
  - Bandit: sample_files/bandit_ringer_test.py
  - Dodgy: sample_files/dodgy_ringer_test.py
  - MyPy: sample_files/mypy_ringer_test.py
  - Semgrep: sample_files/semgrep_ringer_test.py
  - Vulture: sample_files/vulture_ringer_test.py
- The `run_analyzer_task` utility is accessible within the test scope.
- Each `Run` object starts with status `Run.Status.REQUESTED`.
- Task execution updates are persisted in the test database.

**Execution Steps:**

### Analyzer Task Execution

1. Create a `Run` record for each analyzer with status `REQUESTED`.
2. Call `run_analyzer_task(run.id, run.analyzer)`.
3. Refresh the `Run` instance from the database.
4. Inspect its final status and associated findings.

**Expected Result:**

- For valid analyzers (`bandit`, `dodgy`, `mypy`, `semgrep`, `vulture`):
  - Status updates to **COMPLETED**.
  - At least one finding is created (`findings.count() > 0`).
  - Related `Finding` objects exist in the database.
- For an unsupported analyzer (`fake_tool`):
  - Status changes to **ERRORED**.
  - No findings are recorded.

**Post-Conditions:**

- Database reflects the correct final states for each run.
- `Finding` entries exist only for valid analyzers.
- The error path does not create partial or inconsistent data.
- Task behavior remains idempotent and does not affect unrelated runs.
