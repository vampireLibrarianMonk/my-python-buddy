**Test ID:** UT-15-03
**Test Case Name:** Chat Bot Search Query Prompt Validation (Response & Missing API Key)
**Test Type:** Unit
**Test Context:** Local Execution
**Test URL / Location:**

- **File:** `base_application/tests/test_chat_bot.py`

- **Class:** `ChatSearchTests`
  **Methods:**
  - `test_chat_llm_search_prompt`
  - `test_chat_llm_no_brave_api_key`

```bash
python manage.py test base_application.tests.test_chat_bot.ChatSearchTests
```

**Description:**

This test suite will serve to validate behavior of the search query prompt mechanism of the chat bot.

**Preconditions:**

- Django test client is made available.
- `SECURE_SSL_REDIRECT=False` override setting is made to prevent 301 errors.
- Chat endpoint routes (`chat_reset`, `chat_llm`) are configured properly.
- Local GGUF model accessible at `models/<GGUF_FILE_NAME>`.
- Proper NVIDIA Driver and CUDA Runtime is installed.

**Test Data:**

| Field        | Example Value       | Notes                        |
| ------------ | ------------------- | ---------------------------- |
| Query Prompt | `"What is Django?"` | Standard informational query |

**Settings for Failure Simulations:**

| Patches                                 | What Was Patched / Mocked | Purpose of Failure Injection                    |
| --------------------------------------- | ------------------------- | ----------------------------------------------- |
| `override_settings(BRAVE_API_KEY=None)` | Removes Brave API key     | Forces Brave search path to return failure text |

**Automated Execution Steps:**

### Chat LLM Input Validation (`test_chat_llm_search_prompt`)

1. Valid search prompt returns in response `"Django is a Python web framework"`.

### Brave Search API Failure Handling (`test_chat_llm_no_brave_api_key`)

1. Override `BRAVE_API_KEY=None` to simulate when one forgets to record the credential in the .env file.
2. Confirm the request succeeds with **200** but the response includes `"The brave search api has failed."`.

**Expected Result:**

- Search query prompt is deterministic and returns a set of key words checks on the undeterministic search summary.
- Exception conditions are percolated back in a well organized structure for verification.

**Post-Conditions:**

- All responses are structured well (JSON) and predictable.

**Associated Requirements:**
FR-11, FR-15
