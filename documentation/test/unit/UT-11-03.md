**Test Case Name:** Reject Non-.py Upload
**Test Type:** Unit
**Test URL / Location:**

- File: `base_application/tests/test_upload.py`

  **Method:** `test_rejects_non_py`

```bash
python manage.py test base_application.tests.test_upload.UploadViewTests.test_rejects_non_py
```

**Description:**
Ensure non-`.py` uploads are rejected and the page displays the error **“Only .py files are allowed.”**

**Preconditions:**

- Django test client available.
- Test overrides in place (temporary MEDIA_ROOT, `ALLOWED_HOSTS` includes `testserver`, `SECURE_SSL_REDIRECT=False`).
- Authenticated test user (password-change flag cleared), if required.

**Test Data:**

- Filename: `notes.txt`
- Content: `b"not python"` `(MIME: text/plain)`

**Execution Steps:**

1. `POST /` with `file=SimpleUploadedFile("notes.txt", b"not python")` and `follow=True`.
2. Inspect HTTP status and response body.

**Expected Result:**

- Status code **200** (form re-render).
- Error message **“Only .py files are allowed.”** is visible.

**Post-Conditions:**

- No file saved, no database row created.

**Associated Requirements:**
FR-2, FR-11
