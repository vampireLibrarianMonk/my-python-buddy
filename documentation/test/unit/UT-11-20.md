**Description:**
This suite verifies that each static analyzer (`bandit`, `dodgy`, `mypy`, `semgrep`, `vulture`) completes successfully when executed on a **clean** file with no vulnerabilities or issues.

Each analyzer should mark its associated `Run` record as **COMPLETED**, generate a result payload with zero findings → and accurately update the `findings_count` field to `0`.

The tests collectively confirm analyzer consistency and proper completion behavior when no detections are present.

**Preconditions:**

- Authenticated test user with valid session (if required).
- Active test media configuration (`TEMP_MEDIA` or equivalent).
- Each analyzer’s execution function (`run_bandit_analyzer`, etc.) properly registered in the system.
- Each `Run` instance starts in `Run.Status.REQUESTED` state prior to execution.
- Database state and media root isolated for test runs.

**Test Data:**

| Field           | Example Value                                   | Notes                                            |
| --------------- | ----------------------------------------------- | ------------------------------------------------ |
| Analyzer Names  | `bandit`, `dodgy`, `mypy`, `semgrep`, `vulture` | One per test method                              |
| File Name       | `sample_files/sample.py`                        | Clean file containing no security or lint issues |
| Initial Status  | `Run.Status.REQUESTED`                          | Represents analyzer pending execution            |
| Expected Status | `Run.Status.COMPLETED`                          | Analyzer should complete without errors          |
| Findings Count  | `0`                                             | Confirms clean result state                      |
| Result Data     | `result["results"] == []`                       | Empty list confirms no findings generated        |

**Execution Steps:**

### Analyzer Execution on Clean File

1. Create a `Run` record for each analyzer with status `REQUESTED`.
2. Execute the corresponding analyzer function (e.g., `run_bandit_analyzer(run)`).
3. Refresh the `Run` instance to verify post-execution state.
4. Validate status and results fields.

**Expected Result:**

- `Run.status` is **COMPLETED**.
- `run.findings_count` equals `0`.
- The returned analyzer `result["results"]` is an empty list.

**Post-Conditions:**

- Database correctly reflects final status and zero findings for all analyzers.
- No false positives or erroneous findings recorded.
- Each analyzer produces a consistent result schema.
- No side effects or database anomalies occur across runs.
