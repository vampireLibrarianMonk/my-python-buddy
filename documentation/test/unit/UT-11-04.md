**Test ID:** UT-11-04
**Test Case Name:** Size Boundaries (1,000,000 OK / 1,000,001 Too Large)
**Test Type:** Unit
**Test URL / Location:**

- File: `base_application/tests/test_upload.py`
  **Class:** UploadViewTests
  **Method:** `test_boundary_sizes`
  **Context:** Local Execution

```bash
python manage.py test base_application.tests.test_upload.UploadViewTests.test_boundary_sizes -v 2
```

**Description:**
Validate the file-size boundary: exactly 1,000,000 bytes is accepted (redirects to success), while 1,000,001 bytes is rejected with the message **File too large**.

**Preconditions:**

- Django test client available.
- Test overrides in place (temporary MEDIA_ROOT, `ALLOWED_HOSTS` includes `testserver`, `SECURE_SSL_REDIRECT=False`).
- Authenticated test user (password-change flag cleared), if required.

**Test Data:**

- Allowed File:
  - Filename: `ok.py`
  - Content: `b"x"*1_000_000 (1,000,000 bytes)` `(MIME: text/x-python)`
- Rejected File:
  - Filename: `too_big.py`
  - Content: `b"x"*1_000_001 (1,000,001 bytes)` `(MIME: text/plain)`

**Execution Steps:**

1. `POST` / with `ok.py` containing `1,000,000 bytes`.
2. `POST` / with `too_big.py` containing `1,000,001 bytes (follow=True)`.
3. Inspect HTTP statuses and page content.

**Expected Result:**

- `1,000,000 bytes` --> **302** redirect to success page.
- `1,000,001 bytes` --> **200** (form re-render) and contains `File too large`.

**Post-Conditions:**

- Only the boundary-sized file (1,000,000 bytes) is saved; the oversize file is not persisted.

**Associated Requirements:**
FR-11
