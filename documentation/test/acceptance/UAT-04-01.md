# User Acceptance Test 04-01 Database Models and Administration

**Test Type:** User Acceptance
**Context:** Database Models and Administration
**Context Ladder** Local then Cloud Deployment
**Test ID:** UAT-04-01

**Description:**
This `User Acceptance` test validates that, following successful database migrations, the Django administration dashboard correctly registers and displays the Finding, Run and SubmittedFile models per its definition (`models.py`) and administration (`admin.py`). The test confirms that the model's metadata (fields, relationships and inline configurations) are viewable and manageable within the Django Administration interface. A successful migrations imply that Django’s framework automatically enables the administration functionality.

- Finding
- Run
- SubmittedFile

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `SuperUser` has been notified that they have to accept self-signed certificate for HTTPS access.
- Database migrations have been applied successfully using `python manage.py migrate`.
- `SuperUser` credentials are supplied.
- `SuperUser` has uploaded a valid file from `sample_files` below and run at least one `analyzer`.
  - `bandit_runger_test.py`
  - `pickle.py`

## Test Execution Steps

| Step | Action                                 | Expected Response                                                                     |
| ---- | -------------------------------------- | ------------------------------------------------------------------------------------- |
| 1    | `SuperUser` logs into application.     | Application loads successfully.                                                       |
| 2    | `SuperUser` selects `Admin` page.      | Dashboard loads successfully.                                                         |
| 3    | Navigate to **SubmittedFile** section. | `SubmittedFile` model entries are listed.                                             |
| 4    | Select a specific `SubmittedFile`.     | Model characteristics metadata displayed per file drilldown.                          |
| 5    | Navigate to **Runs** section.          | `Run` model entries are listed.                                                       |
| 6    | Select a specific `Run`.               | Inline `Finding(s)` displayed and are selectable with details availabe per drilldown. |

**Post-Condition:**

- `Run` and `Finding(s)` are fully viewable within the dashboard.
