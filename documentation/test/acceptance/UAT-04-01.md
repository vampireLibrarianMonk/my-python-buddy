**Test ID:** UAT-04-01
**Test Case Name:** Database Models and Administration
**Test Type:** User Acceptance
**Context:** Database Models and Administration
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=G5GJRPVu_iI

**Description:**
This `User Acceptance` test validates that, following successful database migrations, the Django administration dashboard correctly registers and displays the Finding, Run and SubmittedFile models per its definition (`models.py`) and administration (`admin.py`). The test confirms that the model's metadata (fields, relationships and inline configurations) are viewable and manageable within the Django Administration interface. A successful migrations imply that Django’s framework automatically enables the administration functionality.

The following models are for consideration:

- Finding
- Run
- SubmittedFile

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- Database migrations have been applied successfully using:
  - `python manage.py makemigrations base_application`
  - `python manage.py migrate`
- `User` has been given starter `SuperUser` credentials and is logged in.
- `User` has uploaded a valid file from `sample_files` below and run `Bandit` analyzer.
  - `pickle.py`

## Test Execution Steps

| Step | Action                                 | Expected Response                                                                      |
| ---- | -------------------------------------- | -------------------------------------------------------------------------------------- |
| 1    | `User` selects `Admin` page.           | Dashboard loads successfully.                                                          |
| 2    | Navigate to **SubmittedFile** section. | `SubmittedFile` model entries are listed.                                              |
| 3    | Navigate to **Runs** section.          | `Run` model entries are listed.                                                        |
| 4    | Select a specific `Run`.               | Inline `Finding(s)` displayed and are selectable with details available per drilldown. |

**Post-Condition:**

- `SubmittedFile`, `Run` and `Finding(s)` are fully viewable within the dashboard.

**Associated Requirements:**
FR-4, FR-9
