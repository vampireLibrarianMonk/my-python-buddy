**Test ID:** UAT-15-01
**Test Case Name:** Chat Bot Generate Code Snippet
**Test Type:** User Acceptance
**Context:** Chat Bot Functionality (Code Snippet Generator)
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=IaxBxMvEq34

**Description:**
This `User Acceptance` test will validate the functionality of the chat bot as it comes to the ability to generate code snippets.

**Preconditions:**

- Computer instance (with cloud a public IP is provided) is provisioned with running code and is accessible to the User.
- User has been notified that they have to accept self-signed certificate for HTTPS access.
- Environment file configured with valid database URL and secrets.
- Database migrations have been applied successfully using:
  - `python manage.py makemigrations base_application`
  - `python manage.py migrate`
- `User` has been given starter `RegularUser` credentials and is logged in.
- `User` has uploaded a valid file from `sample_files` below and run `Bandit` analyzer.
  - `pickle.py`
- `User` has navigated to the analysis results page for the `Bandit` analyzer run.

## Test Execution Steps

- Note that actual values from table row data will differ (analyzer selection) per User input.

| Step | Action                                             | Expected Response                                                                             |
| ---- | -------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1    | User select blue (...) icon.                       | Chat bot window appears.                                                                      |
| 2    | User enters a question from MAT-13-01 or MAT-13-02 | Code snippet is successfully generated in the chat window.<br/>Context token tracker updates. |
| 3    | User refreshes page.                               | Page resets and chat bot converts to (...) icon.                                              |
| 4    | User selects blue icon (...)                       | Chat bot window appears as if it was the first time.                                          |

**Post-Conditions:**

- Chat bot functionality unaffected by refresh of page.
- Chat bot will allow for additional questions.
