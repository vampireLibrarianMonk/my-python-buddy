# User Acceptance Test 15-01 Chat Bot Generate Code Snippet

**Test Type:** User Acceptance
**Context:** Chat Bot Functionality (Code Snippet Generator)
**Context Ladder** Local then Cloud Deployment
**Test ID:** UAT-15-01

**Description:**
This `User Acceptance` test will validate the functionality of the chat bot as it comes to the ability to generate code snippets.

**Preconditions:**

- Computer instance (with cloud a public IP is provided) is provisioned with running code and is accessible to the User.
- User has been notified that they have to accept self-signed certificate for HTTPS access.
- Environment file configured with valid database URL and secrets.
- User has been given starter credentials.
- User has access to `sample.py` for upload.

## Test Execution Steps

- Note that actual values from table row data will differ (analyzer selection) per User input.

| Step | Action                                                               | Expected Response                                                                             |
| ---- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1    | User uploads `sample.py`                                             | Application accepts file and confirms upload.                                                 |
| 2    | User selects `Analyze`, chooses analyzers and selects `Run analysis` | Analyzer page loads, analysis starts with selected analyzers.                                 |
| 3    | User arrives at `Analyze code` page                                  | Page renders with analysis.                                                                   |
| 4    | User select blue (...) icon.                                         | Chat bot window appears.                                                                      |
| 5    | User enters a question from MAT-13-01 or MAT-13-02                   | Code snippet is successfully generated in the chat window.<br/>Context token tracker updates. |
| 6    | User refreshes page.                                                 | Page resets and chat bot converts to (...) icon.                                              |
| 7    | User selects blue icon (...)                                         | Chat bot window appears as if it was the first time.                                          |

**Post-Conditions:**

- Chat bot functionality unaffected by refresh of page.
- Chat bot will allow for additional questions.

FR-15
