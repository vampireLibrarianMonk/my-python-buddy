# User Acceptance Test 03-01 File Persistence

**Test Type:** User Acceptance
**Context:** File Persistence
**Context Ladder** Local then Cloud Deployment
**Test ID:** UAT-03-01

**Description:**
This `User Acceptance` test will validate the file persistence within the application.

As one of the test users, I want to have each uploaded `.py` persisted by a unique identifier (content hash) so that I have assured data provenance.

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- `User` has been given starter `SuperUser` credentials.
- `User` has access to `pickle.py` for upload.

## Test Execution Steps

| Step | Action                                                       | Expected Response                                                                                                 |
| ---- | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 1    | `SuperUser` uploads `pickle.py`.                             | File is written to persistence storage.                                                                           |
| 2    | `SuperUser` navigates to `Admin` then `SubmittedFile` model. | Record includes `Saved name`, `Original name`, `Sha256`, `Uploaded at`, `Analysis status` and `Analysis findings` |

**Post-Condition:**

- `.py` file is stored once and identifiable by its unique hash.

**Associated Requirements:**
FR-3
