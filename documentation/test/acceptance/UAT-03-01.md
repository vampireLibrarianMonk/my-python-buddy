**Test ID:** UAT-03-01
**Test Case Name:** File Persistence
**Test Type:** User Acceptance
**Context:** File Persistence
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=ZKpewTuWlQ0

**Description:**
This `User Acceptance` test will validate the file persistence within the application.

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- `User` has been given starter `SuperUser` credentials.
- `User` has access to `pickle.py` for upload.

## Test Execution Steps

| Step | Action                                                   | Expected Response                                                                                                 |
| ---- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 1    | `User` uploads `pickle.py`.                              | File is written to persistence storage.                                                                           |
| 2    | `User` navigates to `Admin` then `SubmittedFile` model.  | Record includes `Saved name`, `Original name`, `Sha256`, `Uploaded at`, `Analysis status` and `Analysis findings` |
| 3    | `User` selects `View Site` menu option in `Admin` panel. | `User` is redirected back to `Upload` page.                                                                       |
| 4    | `User` uploads `pickle.py` again.                        | Prompt: This file 'pickle-0af5352256b6.py' already exists.<br/>Do you want to reanalyze it?                       |
| 5    | `User` selects **No**                                    | Prompt disappears, `Upload` page remaining.                                                                       |
| 6    | `User` uploads `pickle.py` again.                        | Prompt: This file 'pickle-0af5352256b6.py' already exists.<br/>Do you want to reanalyze it?                       |
| 7    | `User` selects **Yes**                                   | `User` is redirected to analyzer selection menu.                                                                  |

**Post-Condition:**

- `.py` file is stored once and identifiable by its unique hash.

**Associated Requirements:**
FR-3
