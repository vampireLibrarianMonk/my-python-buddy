**Test ID:** UAT-07-01
**Test Case Name:** Metadata Logging
**Test Type:** User Acceptance
**Context:** Metadata Logging
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=I52-Wv6qTiQ

**Description:**
This `User Acceptance` test will validate that each analysis run logs metadata including tool versions, execution details and file hashes to ensure auditability and reproducibility.

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- `User` has been given `RegularUser` credentials and is logged in.
- `User` has uploaded `semgrep_ringer_test.py` from `sample_files` below and run `Semgrep` analyzer.
  - `semgrep_ringer_test.py`

## Test Execution Steps

| Step | Action                                                                             | Expected Response                                                                                                                            |
| ---- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | `User` selects `Semgrep` from the `Analysis Results` for the particular table row. | `User` is redirected to `Analysis Results` page.                                                                                             |
| 2    | `User` reviews `Run` metadata.                                                     | `Analyser Version`, `Documentation`, `Original File Name`, `Status`, `Findings`, `Started` and `Completed` are made available to the `User`. |

**Post-Condition:**

- All metadata fields persist via the `Upload` page table viewable within each `Analysis Results` page for each file.
- Metadata is stored alongside findings for auditing purposes and remains immutable.
