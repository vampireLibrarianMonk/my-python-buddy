# User Acceptance Test 07-01 Metadata Logging

**Test Type:** User Acceptance
**Context:** Metadata Logging
**Context Ladder** Local then Cloud Deployment
**Test ID:** UAT-07-01

**Description:**
This `User Acceptance` test will validate that each analysis run logs metadata including tool versions, execution details and file hashes to ensure auditability and reproducibility.

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- `User` has been given starter credentials.
- `User` has access to a valid file from `sample_files` below and run at least one `analyzer`.
  - `bandit_runger_test.py`
  - `pickle.py`
- Application backend includes installed analyzer tools:
  - `Bandit`
  - `Dodgy`
  - `MyPy`
  - `Semgrep`
  - `Vulture`

## Test Execution Steps

| Step | Action                                                                    | Expected Response                                                                                                                                  |
| ---- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | User uploads a valid `.py` file and triggers analyzer execution.          | Analysis begins and completes successfully.                                                                                                        |
| 2    | `User` selects ``from the`Analysis Results` for the particular table row. | `User` is redirected to `Analysis Results` page.                                                                                                   |
| 3    | `User` review `Run` metadata.                                             | `Analyser Version`, `Documentation`, `File with reference hash`, `Status`, `Findings`, `Started` and `Completed` are made available to the `User`. |

**Post-Condition:**

- All metadata fields persist via the `Upload` page table viewable within each `Analysis Results` page for each file.
- Metadata is stored alongside findings for auditing purposes and remains immutable to the `User` unless they have `SuperUser` credentials or a new analysis run is performed.
