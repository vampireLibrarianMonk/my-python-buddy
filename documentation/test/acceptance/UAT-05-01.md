**Test ID:** UAT-05-01
**Test Case Name:** Analyzer Integration
**Test Type:** User Acceptance
**Context:** Analyzer Integration
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=B3JBxCYzQUc

**Description:**
This `User Acceptance` test will validate the execution and a normalized view of a single run of a static code analyzer against a single `.py` file.

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- Database migrations have been applied successfully using:
  - `python manage.py makemigrations base_application`
  - `python manage.py migrate`
- `User` has been given starter `RegularUser` credentials and is logged in.
- `User` has access to a valid file from `sample_files`.
- Application backend includes at least one configured analyzer tools:
  - `Bandit`
  - `Dodgy`
  - `MyPy`
  - `Semgrep`
  - `Vulture`

## Test Execution Steps

| Step | Action                                                                              | Expected Response                                                                                                          |
| ---- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 1    | Upload a valid `.py` file.                                                          | File stored and visible in submissions table.                                                                              |
| 2    | `User` selects 1 or more analyzers.                                                 | Analyzer(s) chosen is highlighted according to the user selection.                                                         |
| 3    | `User` selects `Analyze`.                                                           | `User` is redirected back to `Upload` page.                                                                                |
| 4    | Pipeline runs selected analyzers.                                                   | `Upload` page's table row specific to file submitted updates per run status and related findings count and severity color. |
| 5    | `User` selects `👁️` for their file output collected `Run` --> 1 or more `Findings`. | `User` is directed to the **Analysis Results** page.                                                                       |

**Post-Condition:**

- `Run` results are normalized into respective `Finding(s)` table and amenable to read code review section.
- Normalized results: Consistent schema returned: `severity`, `rule id`, `message`, `line` and `column`.
