**Test ID:** UAT-06-01
**Test Case Name:** Pipeline Orchestration
**Test Type:** User Acceptance
**Context:** Pipeline Orchestration
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=SJPcDa96yro

**Description:**
This `User Acceptance` test will validate the analyzer pipeline orchestration that begins when a user selects the **Analyze** option, ensuring that multiple analyzers execute in their own asynchronous thread executors.

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- Database migrations have been applied successfully using:
  - `python manage.py makemigrations base_application`
  - `python manage.py migrate`
- `User` has been given starter `RegularUser` credentials and is logged in
- `User` has access to a valid file from `sample_files`.
- Application backend includes installed analyzer tools:
  - `Bandit`
  - `Dodgy`
  - `MyPy`
  - `Semgrep`
  - `Vulture`

## Test Execution Steps

| Step | Action                              | Expected Response                                                                                                          |
| ---- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 1    | Upload a valid `.py` file.          | File stored and visible in submissions table.                                                                              |
| 2    | `User` selects 2 or more analyzers. | Analyzers chosen are highlighted according to the user selection.                                                          |
| 2    | User selects `Analyze` button.      | Analyzer pipeline orchestrator triggered.                                                                                  |
| 3    | Pipeline runs selected analyzers.   | `Upload` page's table row specific to file submitted updates per run status and related findings count and severity color. |

**Post-Condition:**

- `Upload` Page: Analyzer results are displayed as summarized findings (severity --> count).
