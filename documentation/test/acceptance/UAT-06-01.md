# User Acceptance Test 06-01 Pipeline Orchestration

**Test Type:** User Acceptance
**Context:** Pipeline Orchestration
**Context Ladder** Local then Cloud Deployment
**Test ID:** UAT-06-01

**Description:**
This `User Acceptance` test will validate the analyzer pipeline orchestration that begins when a user selects the **Analyze** option, ensuring that multiple analyzers execute in their own asynchronous thread executors and return normalized advice.

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- `User` has been given starter credentials.
- `User` has access to a valid file from `sample_files` below and run at least one `analyzer`.
  - `bandit_runger_test.py`
  - `pickle.py`
- Application backend includes installed analyzer tools:
  - `Bandit`
  - `Dodgy`
  - `MyPy`
  - `Semgrep`
  - `Vulture`
- LLM is integrated and ready to deliver advice within the **Analysis Results** page.

## Test Execution Steps

| Step | Action                              | Expected Response                                                                                                          |
| ---- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 1    | Upload a valid `.py` file.          | File stored and visible in submissions table.                                                                              |
| 2    | `User` selects 2 or more analyzers. | Analyzers chosen are highlighted according to the user selection.                                                          |
| 2    | User clicks `Analyze` button.       | Analyzer pipeline orchestrator triggered.                                                                                  |
| 3    | Pipeline runs selected analyzers.   | `Upload` page's table row specific to file submitted updates per run status and related findings count and severity color. |
| 4    | Normalized advice returned.         | Display results in consistent format with actionable guidance.                                                             |

**Post-Condition:**

- Analyzer results are displayed as normalized findings within the application interface.
