**Test ID:** UAT-02-01
**Test Case Name:** Single File Python Script Upload
**Test Type:** User Acceptance
**Context:** Single File Python Script Upload
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=XnOd2edxCr4

**Description:**
This `User Acceptance` test will validate the file extension handling of the application.

**Preconditions:**

- Computer instance (private or cloud) with a reachable IP is provisioned with the server running the application.
- `User` has been notified that they have to accept self-signed certificate for HTTPS access.
- Database migrations have been applied successfully using:
  - `python manage.py makemigrations base_application`
  - `python manage.py migrate`
- `User` has been given starter `RegularUser` credentials and is logged in.
- `User` has access to `sample.py` for upload.
- `User` has access to `file.txt` for upload.

## Test Execution Steps

| Step | Action                                | Expected Response                                                                                |
| ---- | ------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1    | `User` uploads `sample.py`.           | System checks validity of file extension.                                                        |
| 2    | System validates `.py` format.        | Success: “File 'sample-77e18eb4d18f.py' uploaded successfully.”                                  |
| 3    | `User` selects `Upload another file`. | Redirected back to upload page.                                                                  |
| 4    | Uploads invalid file `file.txt`.      | Error: “There was a problem with your upload. See errors below.<br/>Only .py files are allowed.” |

**Post-Condition:**

- File accepted only if valid `.py` extension.
