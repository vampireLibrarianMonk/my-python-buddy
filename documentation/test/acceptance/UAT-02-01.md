# User Acceptance Test 02-01 Single File Python Script Upload

**Test Type:** User Acceptance
**Context:** Single File Python Script Upload
**Context Ladder** Local then Cloud Deployment
**Test ID:** UAT-02-01

**Description:**
As one of the test users, I want the ability to upload a single `.py` file and receive a clearly understood validation message, so that I know immediately if the submission is valid or not.

**Preconditions:**

- Computer instance (with cloud a public IP is provided) is provisioned with running code and is accessible to the User.
- User has been notified that they have to accept self-signed certificate for HTTPS access.
- Environment file configured with valid database URL and secrets.
- User has been given starter credentials.
- User has access to `sample.py` for upload.
- User has access to `file.txt` for upload.

## Test Execution Steps

| Step | Action                          | Expected Response                                                    |
| ---- | ------------------------------- | -------------------------------------------------------------------- |
| 1    | User uploads `sample.py`        | System checks validity of file extension.                            |
| 2    | System validates `.py` format   | Success: “Valid Python script uploaded successfully.”                |
| 3    | Uploads invalid file `file.txt` | Error: “Invalid submission. Only single Python `.py` files allowed.” |

**Post-Condition:**

- File accepted only if valid `.py` extension.

**Associated Requirements:**
FR-2
