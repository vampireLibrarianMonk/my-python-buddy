**Test ID:** UAT-15-03
**Test Case Name:** Chat Bot ChatSession Model Creation
**Test Type:** User Acceptance
**Context:** Chat Bot Functionality (Model Record Creation)
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=ivlR8l_ebVY

**Description:**
This `User Acceptance` test will validate the functionality of the model record concerning the chat bot code and search functionality.

**Preconditions:**

- Computer instance (with cloud a public IP is provided) is provisioned with running code and is accessible to the User.
- User has been notified that they have to accept self-signed certificate for HTTPS access.
- Environment file configured with valid database URL and secrets.
- Database migrations have been applied successfully using:
  - `python manage.py makemigrations base_application`
  - `python manage.py migrate`
- `User` has been given starter `SuperUser` credentials and is logged in.
- `User` has uploaded a valid file from `sample_files` below and run `Bandit` analyzer.
  - `pickle.py`
- `User` has navigated to the analysis results page for the `Bandit` analyzer run.

## Test Execution Steps

- Note that actual values from table row data will differ (analyzer selection) per User input.

| Step | Action                                                           | Expected Response                                                                                     |
| ---- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1    | User select blue (...) icon.                                     | Chat bot window appears.                                                                              |
| 2    | User enters a question from MAT-13-01 or MAT-13-02               | Code snippet is successfully generated in the chat window.<br/>Context token tracker updates.         |
| 3    | User enters a question from MAT-13-03                            | Search query summary is successfully generated in the chat window.<br/>Context token tracker updates. |
| 4    | User refreshes page.                                             | Page resets and chat bot converts to (...) icon.                                                      |
| 5    | User selects blue icon (...)                                     | Chat bot window appears as if it was the first time.                                                  |
| 6    | User selects Admin                                               | Django Administration Panel appears                                                                   |
| 7    | User selects Runs                                                | Run history is displayed                                                                              |
| 8    | User navigates to their run entry for `pickle.py` and selects it | Inline Finding and ChatSession history is displayed.                                                  |
| 9    | User navigates to `Chat sessions`                                | ChatSession history records are displayed for the `Code` and `Search`.                                |
