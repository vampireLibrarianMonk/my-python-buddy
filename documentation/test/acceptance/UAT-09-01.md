# System Test 09-01 Full File Lifecycle through Analyzer Pipeline

**Test Type:** User Acceptance
**Context:** Full Analyzer Pipeline (Upload to Analysis to Report)
**Context Ladder** Local then Cloud Deployment
**Test ID:** UAT-09-01

**Description:**
This `User Acceptance` test will validate the viability of the analyzer pipeline from upload, templated analysis then deletion.

The Django framework is served by uvicorn which enables https with static file support via Whitenoise. Data is persisted by SQLite.

**Preconditions:**

- Computer instance (with cloud a public IP is provided) is provisioned with running code and is accessible to the User.
- User has been notified that they have to accept self-signed certificate for HTTPS access.
- Environment file configured with valid database URL and secrets.
- User has been given starter credentials.
- User has access to `sample.py` for upload.

### Test Execution Steps

- Note that actual values from table row data will differ (analyzer selection) will differ per User input.

| Step | Action                                                               | Expected Response                                                                     |
| ---- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1    | User uploads `sample.py`                                             | Application accepts file and confirms upload                                          |
| 2    | User selects `View/Download`                                         | Browser opens uploaded file in new tab                                                |
| 3    | User selects `Analyze`, chooses analyzers and selects `Run analysis` | Analyzer page loads, analysis starts with selected analyzers                          |
| 4    | User arrives at `Analyze code` page                                  | Page renders with analysis controls                                                   |
| 5    | User selects `Upload` from top-right menu                            | User is redirected back to submission page with uploaded files table shown            |
| 6    | User selects `View/Download` from uploaded row                       | File opens in a new browser tab                                                       |
| 7    | User selects `Re-run`                                                | Analyzer page opens with previously selected analyzers prefilled                      |
| 8    | User selects `Run analysis` again                                    | Analysis re-runs with same analyzers                                                  |
| 9    | User arrives at `Analyze code` page                                  | Analysis results are shown                                                            |
| 10   | User selects `Upload` again                                          | Redirected back to submission page                                                    |
| 11   | User selects `Delete` for uploaded file                              | Confirmation prompt appears                                                           |
| 12   | Confirmation prompt: "Delete this file? This cannot be undone."      | Prompt displayed with `Cancel` and `OK` options                                       |
| 13   | User selects `Cancel`                                                | File remains, no changes made                                                         |
| 14   | User selects `OK`                                                    | File is deleted, success message: `Deleted 'sample-9be6ce3e361e.py' (944411681ce0…).` |

**Post-Conditions:**

- Upload table is empty.
