**Test ID:** UAT-09-01
**Test Case Name:** Full File Lifecycle through Analyzer Pipeline
**Test Type:** User Acceptance
**Context:** Full Analyzer Pipeline (Upload to Analysis to Report)
**Context Ladder:** Local then Cloud Deployment
**YouTube URL Video Demonstration:** https://www.youtube.com/watch?v=Xbq6adPGrqo

**Description:**
This `User Acceptance` test will validate the viability of the analyzer pipeline from upload, templated analysis then deletion.

The Django framework is served by uvicorn which enables https with static file support via Whitenoise. Data is persisted by SQLite.

**Preconditions:**

- Computer instance (with cloud a public IP is provided) is provisioned with running code and is accessible to the User.
- User has been notified that they have to accept self-signed certificate for HTTPS access.
- Database migrations have been applied successfully using:
  - `python manage.py makemigrations base_application`
  - `python manage.py migrate`
- `User` has been given starter `RegularUser` credentials and is logged in.
- User has access to `sample.py` from `sample_files` for upload.

## Test Execution Steps

- Note that actual values from table row data will differ (analyzer selection) will differ per User input.

| Step | Action                                                                                                   | Expected Response                                                                        |
| ---- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 1    | User uploads `sample.py`                                                                                 | Application accepts file and confirms upload                                             |
| 2    | User selects `View/Download`                                                                             | Browser opens uploaded file in new tab                                                   |
| 3    | User navigates back to `Upload` page.<br>selects `Analyze`, chooses analyzers and selects `Run analysis` | Redirected back to `Upload` page, analysis starts with selected analyzers                |
| 4    | User selects `View File` from uploaded row                                                               | Browser opens uploaded file in new tab                                                   |
| 5    | User navigates back to `Upload` page.<br>User selects `Analyze File` from uploaded row                   | Analyzer page opens with fresh analyzer combobox                                         |
| 6    | User selects a different analyzer set then selects `Run Analysis` again                                  | Analysis runs again with new analyzer set but previous analyzer results remain unchanged |
| 7    | User selects `Delete` for uploaded file                                                                  | Confirmation prompt appears                                                              |
| 8    | Confirmation prompt: "Delete this file? This cannot be undone."                                          | Prompt displayed with `No` and `Yes` options                                             |
| 9    | User selects `No`                                                                                        | File remains, no changes made                                                            |
| 10   | User selects `Delete` for uploaded file                                                                  | Confirmation prompt appears                                                              |
| 11   | User selects `Yes`                                                                                       | File is deleted, success message: `Deleted 'sample-9be6ce3e361e.py' (944411681ce0…).`    |

**Post-Conditions:**

- Upload table is empty.
