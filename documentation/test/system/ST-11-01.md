
**Description:**

This test suite validates the entire health endpoint that is sectioned off into a component by component dashboard. The
essential elements of the dashboard are as follows:

- `Environment:` {dev/test/int/prod}
- `Build:` {local/cloud}
- `Application:`
  - Version
  - Debug
- `REDIS Channel:`
  - ping / pong test
- `System:`
  - CPU
  - Memory
  - GPU
- `Runtime:`
  - python
  - django
  - llama_cpp_python
  - nvidia_driver
  - cuda_runtime_driver
  - cuda_runtime_system
- `Llama Model Inference:`
  - Status
  - Load Time
  - Model Name
  - GPU(s) Used:
  - Sample Output:

**Preconditions:**

- Django test client available.
- Health endpoint mapped to `healthz`.
- Test `SuperUser` created and authenticated.
- Underlying hardware, software and runtime have been properly installed.

**Test Data:**

| Field    | Example Value  | Notes                          |
| -------- | -------------- | ------------------------------ |
| Username | auto‑generated | Deterministic override allowed |
| Email    | auto‑generated | Used to create superuser       |
| Password | random token   | Stored and reused during test  |

**Automated Execution Steps:**

### 1️. Health Endpoint Rendering

1. Authenticate superuser.
2. Call `/healthz`.
3. Confirm **200** and presence of required sections (application, dependencies, system, runtime, llama).

### 2️. Application Section Validation

1. Confirm keys: `name`, `env`, `version`, `build`, `debug`.
2. Validate values are non‑empty and version follows `digits.digits(.digits)` pattern.

### 3️. Dependency & System Metrics Validation

1. Confirm Redis keys and versioning.
2. Validate CPU model, usage %, cores and speed.
3. Validate memory usage values and logical constraints.
4. Validate GPU device list and fields.

### 4️. Runtime Version Validation

1. Confirm expected runtime version keys.
2. Enforce version number regex.

### 5️. Llama Runtime Validation

1. Verify model name ends in `.gguf`.
2. Validate load time, sample output and GPU used.

**Expected Result:**

- Health dashboard loads successfully and returns **200**.
- All sections include required keys and valid values.
- All metrics conform to expected formats.
- Llama inference check returns expected metadata.

**Post-Conditions:**

- No persistent artifacts or alterations to the underlying hardware, software or runtimes.
