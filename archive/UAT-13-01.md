# Model Acceptance Test 13-01 GGUF Conversion Confirmation

**Test Type:** Model Acceptance
**Context:** GGUF Model Prompts via llama-cpp
**Context Ladder:** GGUF Export → Quantization → Metadata Readback
**Test ID:** UAT-13-01

**Description:**
This `User Acceptance` test validates the usability of the python notebook `Fine_Tuning_Model.ipynb` (artifact re-creation), which confirms that the quantized GGUF model created via `llama.cpp` from a merged LoRA fine-tuned model retains its expected metadata values and is properly accessible via the `llama-cpp-python` interface. The test focuses on validating the correct number of transformer layers (`llama.block_count`) and ensuring GPU inference via metadata visibility.

**Preconditions:**

- Git is installed.
- Python 3.12.X is installed along with its associated pip.
- LLama-CPP repository is cloneable (versioning is not available).
- GPU-enabled environment (e.g., A100 with CUDA 12.4+) is accessible.
- llama.cpp is cloned, built and llama-cpp-python (>=v0.3.16) are installed and configured.
  - Required wheel `llama_cpp_python-0.3.16-cp312-cp312-linux_x86_64.whl` is installed.
- Full-precision merged model has been converted to GGUF using `/content/llama.cpp/convert_hf_to_gguf.py`.
- The GGUF model is quantized (e.g., Q4_K_M) and saved as `/content/model-q4_k_m.gguf`.
- Merged model and GGUF model hashes are computed via `compute_sha256()` and logged.
- All environment variables (e.g., `MAIN_FILE_NAME`, `GOOGLE_MODEL_PATH`) are set.
- llama-cpp-python's `Llama` interface is available for metadata extraction.

## Test Execution Steps

| Step | Action                                                                        | Expected Response                                                    |
| ---- | ----------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 1    | Ensure `llama_cpp` is importable and version is ≥ 0.3.16.                     | Printout confirms version (e.g., `llama-cpp-python: 0.3.16`).        |
| 2    | Run `llama_print_system_info()` from `llama_cpp.llama_cpp`.                   | Output includes `CUDA = 1` and/or `cuBLAS = 1` confirming GPU build. |
| 3    | Initialize `Llama` instance with quantized GGUF file using `vocab_only=True`. | Model loads without error; metadata is available.                    |
| 4    | Dump metadata and confirm key `llama.block_count` is present.                 | Output shows a positive integer for transformer layers.              |
| 5    | Extract and log SHA-256 hash of GGUF model.                                   | Printed hash string and saved to timestamped file.                   |
| 6    | Ensure hash and quantized model are uploaded to Google Drive.                 | Google Drive contains the `.gguf`, `.log`, and `.txt` hash files.    |
