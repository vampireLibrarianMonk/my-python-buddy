# User Acceptance Test 12-01 LLM Fine-Tuning and Evaluation

**Test Type:** User Acceptance
**Context:** LLM Fine-Tuning and Evaluation
**Context Ladder:** Hyperparameter Configuration → Training Execution → Metrics Logging
**Test ID:** UAT-12-01

**Description:**
This `User Acceptance` test validates the usability of the python notebook `Fine_Tuning_Model.ipynb` (artifact re-creation), following completion of the Llama 7B fine-tuning regime, the notebook successfully records all configured **hyperparameters** and **evaluation metrics** for the trained model. This recording of metadata ensures that the fine-tuning was run under the expected configurations and is reproducible with the output a designated Google Drive path.

Fine-tuning is performed via the **SFTTrainer** using LoRA-based parameter-efficient fine-tuning on the _NousResearch/Llama-2-7b-chat-hf_ model with the _minipython-Alpaca-14k_ dataset. Evaluation metrics such as **loss** and **perplexity** are computed after training completion and saved as a timestamped log file.
